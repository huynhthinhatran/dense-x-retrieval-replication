# Dense X Retrieval — Downscaled Replication

Replication (thu nhỏ) của paper **Dense X Retrieval: What Retrieval Granularity Should We Use?** cho môn SEG301 (Search Engines).

## Paper

- **Paper:** Tong Chen, Hongwei Wang, Sihao Chen, Wenhao Yu, Kaixin Ma, Xinran Zhao, Hongming Zhang, Dong Yu. *Dense X Retrieval: What Retrieval Granularity Should We Use?* EMNLP 2024.
  - arXiv: https://arxiv.org/abs/2312.06648
  - PDF: https://arxiv.org/pdf/2312.06648
- **Code / data của tác giả:** https://github.com/chentong0/factoid-wiki
- **FactoidWiki (HuggingFace):**
  - Proposition: https://huggingface.co/datasets/chentong00/factoid-wiki
  - Sentence: https://huggingface.co/datasets/chentong00/factoid-wiki-sentence
  - Passage: https://huggingface.co/datasets/chentong00/factoid-wiki-passage
- **Propositionizer:** https://huggingface.co/chentong00/propositionizer-wiki-flan-t5-large

## Mục tiêu

Kiểm chứng **xu hướng tương đối** Proposition > Sentence > Passage trên một corpus thu nhỏ (8,000 pages), không nhằm khớp số tuyệt đối của paper.
